# Invite-only registration, no email infrastructure for the MVP

GripTrack is used by a small, known group (the owner plus boulder-hall
friends), not the public, and deployment is local-only for now. Rather than
open self-signup — which would require real safeguards (email verification,
rate-limiting) — registration requires an `Invite` generated by an existing
user. This lets the MVP skip standing up any email-sending infrastructure
entirely (no verification emails, no password-reset-via-email). Open signup
can be added later if the app ever needs to grow beyond people the owner
personally invites.

For the same reason, there's no self-service password reset: if a user
forgets their password, the owner/admin resets it directly (a small admin
action or CLI script) rather than building an email-based reset flow for a
handful of known users.
